1️⃣ ¿Qué es un grafo?

Un grafo es una estructura utilizada en ciencias de la computación para conectar elementos entre sí. Cada elemento se conoce como nodo y las conexiones se llaman aristas. 

   A --- B
   |   / |
   |  /  |
   C     D
    \   /
      E

2️⃣ Formas de representar un grafo

📌 Lista de adyacencia

A → B, C
B → A, C, D
C → A, B, E
D → B, E
E → C, D

📌 Matriz de adyacencia

    A B C D E
A: 0 1 1 0 0
B: 1 0 1 1 0
C: 1 1 0 0 1
D: 0 1 0 0 1
E: 0 0 1 1 0

3️⃣ Recorridos comunes

🔍 Búsqueda en anchura (BFS)

BFS(grafo, inicio):
  crear una cola
  marcar inicio como visitado

🧠 Búsqueda en profundidad (DFS)

DFS(nodo):
  marcar nodo como visitado
  visitar vecinos no visitados
